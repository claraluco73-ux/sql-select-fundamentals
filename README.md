¿Por qué es mala práctica usar SELECT * en producción? 
Porque SELECT * trae todas las columnas de una tabla. Eso puede generar varios problemas: Menor rendimiento: devuelve más datos de los necesarios, lo que consume más tiempo y recursos, especialmente en tablas grandes. Mayor tráfico de datos: se envía información innecesaria entre la base de datos y la aplicación.
